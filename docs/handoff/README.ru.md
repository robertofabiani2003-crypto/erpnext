# Снимок передач между чатами

Здесь сохранены несекретные отчёты из соседней папки `ERPNext-handoff` на момент
синхронизации 11.11.2026. Статусы внутри файлов отражают время их написания:
например, предварительная проверка локализации ещё ожидает работу её исполнителя.
Более поздний файл передачи или новая проверка имеют приоритет над старым снимком.

Эта папка содержит документацию, не действующую конфигурацию и не базу ERPNext.
Оригинальная папка обмена вне Git сохранена. Повторную синхронизацию её новых
изменений нужно выполнять отдельным commit после проверки отсутствия секретов.
